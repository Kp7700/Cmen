// 01 — why

Forty years of C. One unfinished conversation.

Most languages are named after coffee, gemstones, or whichever letter got there first. We looked at everything the C family built — operating systems, databases, entire careers — and asked the question nobody else dared to ask: what if the next generation was conceived in the open?

Cmen is a small, coherent, genuinely working language wrapped in exactly one joke. Underneath the terminology you'll find values, variables, branching, loops, and functions — everything a first program needs, nothing it doesn't. The interpreter on this page is real. The commitment to the bit is also real.

We believe a programming language should be memorable. You will forget semicolon rules. You will never forget what ejaculate() does.

Is the name a double entendre?

The name is a single entendre. We checked with legal. Legal resigned.

Is Cmen production-ready?

It is ready in the way a teenager is ready.

What does it compile to?

This page, mostly. The playground is a full interpreter running locally in your browser — no servers, no build step, no consequences.

Can I use it at work?

Technically. HR involvement is strongly correlated with the first code review.

// 02 — features

Features engineered for the next generation.

Every feature was reviewed, debated, and approved by a committee that no longer speaks to each other.

01 Controlled Release A dedicated output function with a name you will never forget, never mishear on a video call, and never explain to a coworker without consequences. ejaculate() writes to stdout and to your permanent record.
02 Genetic Variables Values are declared with gene and carried through the program's lifecycle. Constants are seeded once and locked at conception. Some things you just don't mutate.
03 Mutation Support Reassign any gene with mutate. Change your values without an existential crisis — the runtime quietly remembers what you used to be, so you don't have to.
04 Low-Level Ambitions High-level convenience, low-level emotional stability. Close enough to the metal to feel important; far enough away not to get hurt.
05 Reproducible Builds Deterministic output on every run, verified by our test suite (one test). The compiler itself promises absolutely nothing about your lineage.
// 03 — syntax

The whole language, at a glance.

Cmen has eleven keywords. You already understand all of them, which is either great design or a problem for the orientation session.

cum main { ... }Declares a block of execution. cum main is where every program begins. All functions are conceived the same way.
gene x = v;Declares a mutable variable, capable of carrying a value through the program's lifecycle.
seed x = v;Declares a constant. Fixed at conception. Attempting to mutate one is a compile-time lesson.
mutate x = v;Reassigns an existing gene. Change is possible. Growth is optional.
mate a + bThe affinity operator. Combines values; if either side is text, they concatenate. Opposites attract; strings merge.
grow i from 1 to 5 { ... }Repetition. Counts inclusively from start to end — Cmen believes in commitment.
when (c) { ... } otherwise { ... }Conditional execution. Fertilizes exactly one branch.
release v;Returns a value from a cum block. Emits it into the world.
die("reason");Terminates execution immediately. For when the program has seen enough.
ejaculate(v, ...);Standard output. Evaluates the expressions and writes them to the console. You will never look this up twice.
